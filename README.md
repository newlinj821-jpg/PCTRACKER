# Pretty Girl — Cycle Companion

Free, ad-free, mobile-first period tracking PWA. Netlify: publish repository root; no build command.

Features: cycle logging, estimates, monthly calendar, daily mood/flow/pain/notes, history, backup import/export, offline caching.

Privacy: local browser storage only, not encrypted. No two-device synchronization or remote partner access yet. The cycle owner must explicitly consent to sharing. Estimates are not contraception or medical diagnosis.

Install on iPhone: Safari → Share → Add to Home Screen.
